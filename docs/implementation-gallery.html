Honest V0 boundary

Vibe Tracks does not yet launch agents, infer dependencies, ingest transcripts, create notes, deliver feedback, or write through Obsidian's live editor buffer. Do not mutate a note that is open and unsaved in Obsidian from the standalone app; the future custom-view wrapper should use Obsidian's frontmatter API. This first slice establishes the stable coordination surface those capabilities can safely build on.

Try it: python3 -m vibetracks examples/pyblocks/Project.base --open-browser
