# Home shell + Zen review — design prototype (2026-10-06)

Clickable mock (fixture data, nothing wired) chosen over three review rounds:
V1 Calm Rows with an always-on sidebar, Rows / Table / Board / Cards views over one
dataset, aligned columns, soft-KPI cards↔rows, and Zen-mode review (triaged, media
first, Claude-style options). Open `app.html` directly in a browser.

`src/` is the prototype source; `build.py` and `shoot*.py` rebuild the media-rich
report, which lives (git-excluded, with its captures) at
`reports/media/vibetracks-home-proposals-2026-10-06/index.html`.
