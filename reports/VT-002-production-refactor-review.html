What changed

The Codex V0 became a production tool with a dispatcher protocol. The monolithic model.py split into six focused modules (errors · notes · descriptor · project · edits · scaffold, facade kept); the panel gained two new revision-fenced writes — dependency editing and feedback comments — so the graph is now a genuinely shared control surface; the descriptor grew area-catalog memory (name → description) that agents read before tagging and grow as themes emerge; and /vibetracks now turns any Claude Code or Codex session into a dispatcher for the nearest repo (vibetracks init/new/status/comment/inspect/agent). The UI was rebuilt ink-on-paper per the note's open TODO.
